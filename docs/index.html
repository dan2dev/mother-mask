Lightweight JavaScript input masking

mother-mask formats form fields as people type, paste, select, and replace text. Use it in plain browser apps or alongside any UI framework because the package only needs an HTMLInputElement.

Pattern masks

Add phone, date, CPF, CNPJ, CEP, SSN, ZIP+4, postal code, IBAN, VAT ID, license plate, credit card, and custom input masks with bind(). Add custom tokens, case transforms, Unicode letters, and layouts chosen from the input value.

Decimal and currency masks

Format money, quantities, localized separators, prefixes, suffixes, and negative values with bindDecimal() and decimal helper exports.

Small browser package

Ships with zero runtime dependencies, TypeScript types, ESM, CJS, and UMD builds for npm installs or direct CDN usage.
